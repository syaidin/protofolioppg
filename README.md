# 📚 E-Portfolio Mahasiswa PPG

E-Portfolio digital untuk Program Pendidikan Profesi Guru (PPG) Pra Jabatan - Bidang Studi Informatika.

## 🎓 Tentang Project

Website portfolio ini dibuat sebagai dokumentasi perjalanan pembelajaran selama mengikuti Program PPG di Universitas Negeri Surabaya (UNESA). Portfolio ini mencakup refleksi pembelajaran, dokumentasi kegiatan, dan hasil karya selama program PPG.

## ✨ Fitur

- **Profil Mahasiswa** - Informasi lengkap tentang mahasiswa dan daerah asal
- **Lokasi Perkuliahan** - Detail kampus dan lingkungan perkuliahan
- **Refleksi Mata Kuliah** - Refleksi 4C dari setiap mata kuliah (Semester 1 & 2)
- **E-Portfolio UTS** - Produk pembelajaran dan analisis mendalam
- **E-Portfolio UAS** - 6 komponen analisis praktik mengajar:
  - Analisis Rancangan/Perencanaan Pembelajaran
  - Analisis Materi Pembelajaran
  - Analisis Media Pembelajaran
  - Analisis Video Pelaksanaan Praktik Mengajar
  - Analisis Kegiatan Nonmengajar
  - Instrumen Penilaian
- **Model Guru yang Dituju** - Visi dan misi sebagai pendidik
- **Dokumentasi PPG** - Galeri foto kegiatan dan momen berharga

## 🚀 Cara Menjalankan

### Metode 1: Local Server (Recommended)

1. Pastikan Python sudah terinstall
2. Double-click file `start-server.bat`
3. Buka browser dan akses `http://localhost:8000`

### Metode 2: Langsung Buka File

1. Double-click file `index.html`
2. Website akan terbuka di browser default

## 🛠️ Teknologi yang Digunakan

- **HTML5** - Struktur konten
- **CSS3** - Styling dan animasi
- **JavaScript (Vanilla)** - Interaktivitas dan dinamis konten
- **Responsive Design** - Mobile-friendly
